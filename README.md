# 🎓 Student Grade Manager

A simple Python project for managing student information, calculating grades, and determining whether each student has passed or failed.

## 📌 Project Overview

This project reads student information from a text file, stores the data using Python dictionaries, calculates each student's average grade, checks the result, and saves the final results in a separate file.

The project was created as a practical application of Python Fundamentals.

## ✨ Features

* 📂 Read student data from a text file
* 👤 Store student information using dictionaries
* 🧮 Calculate the average grade automatically
* ✅ Determine whether a student passed or failed
* 📄 Display the results
* 💾 Save the results to a separate text file
* ⚠️ Validate the calculated grade

## 📁 Project Structure

```text
student-grade-manager/
│
├── README.md
├── main.py
├── students.txt
└── results.txt
```

### `main.py`

Contains the main program logic, including reading the data, calculating grades, checking the results, and saving the output.

### `students.txt`

Contains the student information and their subject grades.

Example:

```text
Amat,76,80,90,60,15
Amar,80,50,90,100,14
Chada,45,80,30,5,12
```

### `results.txt`

Contains the results generated by the program after calculating the students' grades.

## ▶️ How It Works

The program follows these steps:

```text
students.txt
     ↓
Read student data
     ↓
Convert data into dictionaries
     ↓
Calculate average grade
     ↓
Check Pass / Fail
     ↓
Display results
     ↓
Save results to results.txt
```
